# 中文标识符版本（存档）

本目录是 **v1.0 中文标识符版**的完整源码存档，取自 git 标签 `v1.0-zh-source`（2026-11-26）与分支
`zh-source-backup`。

## 为什么保留这一份

本项目面向**强本地化团队**：代码里的名字与电气图纸、配置 JSON、界面文案一一对应，
现场工程师交接时不必在脑子里再做一层翻译。

开源后为了让外部读者能直接读懂，主线代码已改为**英文标识符**；**注释仍然全部是中文**
——解释"为什么这么做"的部分留在中文，才能保住现场经验的原味。

两套源码的关系：

| | 主线 `src/` + `config/` | 本目录 `legacy/zh-CN/` |
|---|---|---|
| 标识符 | 英文（`AlarmScanService`、`_activeId`） | 中文（`报警扫描服务`、`_活动标识`） |
| 注释 | 中文 | 中文 |
| 定位 | 官方维护，发布包由它构建 | **存档**，与主线语义等价，不再随主线演进 |
| 参与构建 | 是 | 否 |

## 怎么用

本目录**不参与构建**：`PlcHmi.slnx` 只列 `src/` 下的五个工程，这里的 `.cs` / `.xaml`
不会被编译，也不会被 `tools/` 下的门禁脚本扫描。

需要以中文版继续开发时，把 `legacy/zh-CN/` 下的 `src/`、`config/`、`tools/` 覆盖回仓库根目录即可
（覆盖前建议先提交或另建分支）。

## 与主线的一致性

两套源码由同一次语义级改名生成，**没有逻辑差异**：

- 主线：0 警告 0 错误构建、612/612 测试通过、`--smoke` 界面自检通过；
- 存档：取自改造前的 `v1.0` 快照，本身即为当时的通过状态；
- 改名只动标识符，注释、字符串文案（界面文字、日志、异常提示）全部保留中文。
