> 打印贴工位 / 或直接复制进 PR 描述。配套文档：`docs/04-代码审查标准与流程.md`

## 提交前 · 作者自检（红灯不许提交）

```
[ ] pwsh tools/verify.ps1           → 一条命令跑完全部门禁（推荐）
    或分步：
[ ] dotnet build PlcHmi.slnx -warnaserror --no-incremental -p:WarningsNotAsErrors=NU1900
                                    → 0 警告 0 错误（编译器/分析器）
[ ] dotnet test  PlcHmi.slnx        → 全部通过（基线 406）
[ ] 涉及 UI      → PlcHmi.App.exe --smoke 通过（8 页 + 4 对话框 + 交互自检）
[ ] 涉及配色    → python tools/check_contrast.py 全部 PASS
[ ] 涉及规模    → python tools/check_thresholds.py PASS
[ ] 涉及地址/编解码 → 附实测向量单测
[ ] 涉及改名   → 同步了 XAML 绑定 / config/*.json 键 / 枚举字符串（详见 04 文档 §3.4）
[ ] 新增标识符符合中文命名规范（英文仅限框架约定成员与领域专名例外清单）
```

> ⚠️ **`--no-incremental` 不能省。** 增量编译会跳过未改动的项目，
> 上游引入的警告在热树上根本不会重新报告 —— 门禁会假绿。
> 这个盲区真实发生过：同一棵树，带增量报 0 警告，强制重编报 1 个错误。

> **`WarningsNotAsErrors=NU1900` 是刻意的。** NuGet 取漏洞数据失败属于网络问题，
> 不加这条，CI 抖一下网络就会以 "error" 名义把构建判红，且报错指不到任何代码。
> **其余任何警告仍然一律判红**，这条豁免只针对 NU1900。

## 审查中 · 通用五线

| | 检查点 |
|---|---|
| **正确性** | 边界值（0 / 空 / 索引 99 / 负坐标）｜循环 ±1 偏移｜null 路径｜异常路径是否有兜底 |
| **安全** | 外部输入（JSON / 输入框 / CSV / PLC 原始数据）是否校验｜权限是否在**服务层**校验｜日志有无泄露密钥 |
| **可维护** | 文件 < 400 行｜函数 < 50 行｜命名表意且符合中文规范（04 §3.4）｜魔法数字已具名｜重复逻辑已抽 |
| **性能** | 轮询回调用内有无分配 / 字符串拼接｜是否逐点读 PLC（应批量）｜UI 线程有无阻塞 |
| **测试** | 核心逻辑有测试｜覆盖失败路径｜断言未被削弱 |

## 审查中 · 工控红线（🔴 判定标准）

### R1 地址与字序
```
[ ] 地址落在 recipe-config.json 合法区间（参数地址只允许 D1200–D1799；点动为 D 字内位如 D1210.2）
[ ] 未绕过 寄存器编解码器 手写字序       → 违反 = 🔴
[ ] 32 位编解码改动附实测向量单测         → 缺失 = 🔴
[ ] 坐标比较用容差 0.005，未用 ==         → 用 == = 🔴
[ ] 示教点按轴分区读（4 次 × 20 字）      → 跨轴连续读 = 🔴
[ ] 报警源仅 M500–M600(FC01) / D550–D554(FC03) → 混用 = 🔴
```

### R2 线程与 UI
```
[ ] UI 切换用 BeginInvoke                → 用 Invoke = 🔴
[ ] 未用 SemaphoreSlim.Wait()            → 用了 = 🔴（改 await WaitAsync）
[ ] 新增 async void 仅限事件处理器 + try/catch → 其他 = 🔴
[ ] CPU 密集已 Task.Run 移出 UI 线程      → 未移 = 🟡
[ ] 后台服务有 CancellationToken + Dispose → 缺失 = 🟡
[ ] 事件流订阅者在构造函数拉了一次快照      → 缺失 = 🟡
```

### R3 数据落盘
```
[ ] 写文件是原子的（.tmp + File.Move）     → recipes/users 非原子 = 🔴，其余 = 🟡
[ ] 原子写是否真的落盘（FlushFileBuffers）  → 只 Dispose 不刷盘 = 🟡（断电后文件可能是 0 字节）
[ ] .bak 是否真的会被读（配置文件加载器）  → 只写不读 = 🔴（备份是死的，等于没有）
[ ] 主文件为 0 字节时是否仍轮换成 .bak     → 照常轮换 = 🔴（亲手把唯一好副本覆盖掉）
[ ] recipes.json 只经 配方存储 写入       → 另建副本 = 🔴
[ ] 参数只在 下发/切换机种 时写 PLC；示教点只在 示教/下发本面 时写
                                          → TextChanged 里直写 = 🔴
[ ] 未启用面在服务层抛异常拦截             → 只靠界面置灰 = 🟡
[ ] 面启用默认 false                      → 默认 true = 🔴
[ ] 加载失败是否登记到 配置健康接口 并在界面示警 → 只写日志 = 🟡
     （配置静默降级成空数据：程序照常启动、界面显示"无报警"，
       而每个故障位都被无视 —— 崩溃看得见，失去报警看不见）
```

### R4 PLC 交互
```
[ ] 状态字经 映射状态字() 映射            → 直接强转 = 🔴
[ ] 手动/点动只置位 M 区，不直写 Y         → 直写 Y = 🔴
[ ] 常闭点标 inverted: true               → 漏标 = 🟡
[ ] 写命令走串行队列                      → 并发写 = 🟡
[ ] 重连有退避且不吞连接异常               → 静默重试无日志 = 🟡
[ ] 点动停止路径无条件生效（不校验使能）    → 使能断开时拒绝停止 = 🔴
[ ] 点动按钮所在页是否开了 PanningMode     → 开了 = 🔴
     （ScrollViewer 会在手指拖动时抢走触摸，按钮收不到 MouseUp，轴一直动）
```

### R5 权限与配置化
```
[ ] 每个写操作声明所需 Permission          → 缺失 = 🟡
[ ] 写操作在**服务层**经 权限守卫接口 校验   → 只在 ViewModel 校验 = 🔴
     （界面隐藏按钮只是防误触，不是边界；绕过界面的成本极低）
[ ] 管理员专有功能（延时表/按钮表/报警/元件编辑）双重校验 → 缺失 = 🔴
[ ] 新点位/报警/元件进 JSON，未硬编码       → 硬编码 = 🟡
[ ] XAML 新增 StaticResource 键存在于 Themes/*.xaml → 不存在 = 🔴
[ ] 改名已同步 绑定路径/配置键/枚举字符串   → 漏改 = 🔴（编译测试全绿但运行时断）
```

## 严重度标记（统一语言）

| 标记 | 含义 | 处理 |
|---|---|---|
| 🔴 | 数据丢失 / 设备异常动作 / 安全 / 死锁 / 崩溃 / 破坏契约 | **必修，不合入** |
| 🟡 | 缺校验 / 缺测试 / 命名费解 / 性能隐患 / 重复代码 | 原则本次修，可延期须写明理由 |
| 💭 | 风格 / 文案 / 注释 / 替代写法 | 不阻塞，作者可忽略 |

> 不得用 🔴 表达个人偏好。不得把 🔴 降级为主管裁决。
