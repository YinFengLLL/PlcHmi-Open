## 影响范围（务必逐项确认）

- [ ] 是否改动 **Modbus 地址 / 寄存器布局**？ → 若是，列出受影响地址段
- [ ] 是否改动 **字序 / 编解码逻辑**？ → 若是，附实测向量
- [ ] 是否改动 **落盘文件格式**（recipes.json / users.json / alarms.json …）？→ 若是，说明**向后兼容性**
- [ ] 是否改动 **权限判定**？ → 若是，列出受影响的角色
- [ ] 是否改动 **线程 / 定时器 / 生命周期**？ → 若是，说明取消与释放路径
- [ ] 是否新增 **配置项**？ → 若是，同步更新 `config/*.json` 与文档
- [ ] 是否**改名**（属性 / 命令 / 枚举成员）？ → 若是，列出已同步的 绑定路径 / 配置键 / 枚举字符串用法

## 审查等级

- [ ] **L1 轻量**（注释/文案/样式，不改逻辑）
- [ ] **L2 标准**（业务逻辑 / 服务层 / ViewModel）
- [ ] **L3 重度**（通信层 / 地址映射 / 编解码 / 权限 / 落盘）→ **需要 2 人审**
