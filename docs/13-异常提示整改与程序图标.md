# 异常提示整改与程序图标

**日期：** 2026-10-12

## 一、现象

顶栏长期挂着红条：

```
程序异常（已记录日志，可继续操作）：AggregateException：A Task's exception(s) were not observed …
```

## 二、排查（日志实证）

日志目录：`<程序目录>/logs/plchmi-<yyyyMMdd>.log`。

```powershell
Select-String logs\plchmi-20261012.log -Pattern '未观察到的后台任务异常' | Select-Object -Last 20
```

命中的是**同一条异常反复出现**（一天内数十次）：

```
[ERR] 未观察到的后台任务异常
System.AggregateException: A Task's exception(s) were not observed …
 ---> System.Net.Sockets.SocketException (995): 由于线程退出或应用程序请求，已中止 I/O 操作。
   at System.Net.Sockets.TcpClient.CompleteConnectAsync(Task task)
```

## 三、根因

1. **它不是程序缺陷，是"没插网线"。** `SocketError 995 = ERROR_OPERATION_ABORTED`：对
   `192.168.1.10:502` 的 TCP 连接从未成功（虚拟/真实 PLC 不在线），连接任务在超时或被
   `Dispose` 时中止，异常被留在**无人 await 的任务**上。
2. **为什么"没人观察"：** `FluentModbusTCP客户端.异步连接` 里
   `Task.Run(() => _客户端.Connect(...))` —— FluentModbus 的 `Connect` 是同步阻塞调用，
   其内部 `ConnectAsync` 在超时时被丢弃，任务异常直到 **GC 时**才通过
   `TaskScheduler.UnobservedTaskException` 浮出来。也就是说：**横幅显示的时刻与故障发生的时刻
   毫无关系**，这也是它看起来"莫名其妙老弹"的原因。
3. **真正的失败原因早就记过日志了**（连接层 `LogWarning` 「连接 PLC 192.168.1.10:502 失败」），
   顶栏那条只是同一件事的"回声"，而且带着 `AggregateException` 这种没人看得懂的词。

## 四、整改

### 1. 异常分级：`运行期错误类别`（`src/PlcHmi.App/Services/RuntimeErrorService.cs`）

| 类别 | 判定 | 横幅 | 计入"建议重启" |
|---|---|---|---|
| `程序异常` | 其余全部（严进宽出，宁可多报） | 红条 · 「程序异常（已记录日志，可继续操作）」 | 是 |
| `设备未连接` | Socket / 超时 / IO / `AggregateException` 内含上述 / 文案含"未连接" | 橙条 · 「PLC 未连接，数据未刷新」 | **否**（连接抖十次也不代表程序不可信） |

判定入口：`异常处理器安装器.是连接类异常`（`src/PlcHmi.App/Services/CrashGuard.cs`）。

### 2. 三个全局处理器统一走分级（`异常处理器安装器.安装`）

- `DispatcherUnhandledException`、`AppDomain.UnhandledException`、`TaskScheduler.UnobservedTaskException`
- 连接类：日志降级为 `Warning` + 一句「已在连接层记录，按可预期状况处理」，横幅走橙条
- 真缺陷：日志 `Error`，横幅走红条

### 3. 设备类横幅会自动消失（`MainViewModel.刷新运行期错误`）

设备类提示描述的是**此刻的连接状态**，不是历史故障：
`连接管理器.状态已变更` 触发重算，一旦变回**已连接**，橙条立即收起。文案：

```
PLC 未连接，数据未刷新（连接恢复后自动消失；各页显示的是上次读到的值）
```

### 4. 代码位置（拆分守 400 行门禁）

| 文件 | 职责 |
|---|---|
| `src/PlcHmi.App/Services/CrashGuard.cs` | 全局异常处理器安装 + 异常分级 + 横幅文案常量 |
| `src/PlcHmi.App/Services/RuntimeErrorService.cs` | 错误收集：类别、最后错误、重启统计 |
| `src/PlcHmi.App/ViewModels/MainViewModel.Banners.cs` | 三条横幅（配置降级 / 运行期异常 / 活动报警）的刷新 |

## 五、程序图标

`src/PlcHmi.App/app.ico`，由 `tools/make_app_icon.py` 生成（**纯标准库**，无 Pillow 依赖）。

- 图形：主蓝渐变圆角方块 + 白色十字槽螺丝头 + 右下小胶滴 —— 对应"锁付 + 点胶"两半工艺
- 刻意不做齿轮/机器人：任务栏与 Alt-Tab 实际只有 16–32px，细节多的图形会糊成一团；
  这里只有三个形状，缩到 16px 仍是"蓝底 + 白螺丝 + 一滴胶"
- 内含 256 / 64 / 48 / 32 / 16 五档 PNG 条目（Vista+ 支持 PNG-in-ICO），自带 4× 超采样抗锯齿
- 三处复用同一个文件：exe 图标（`<ApplicationIcon>`）、窗口图标（`Window.Icon`）、
  标题栏 Logo（`Image Source="pack://application:,,,/app.ico"`）——避免"任务栏一个样、界面另一个样"

改图标：编辑 `tools/make_app_icon.py` 后重跑

```powershell
python tools/make_app_icon.py
```
